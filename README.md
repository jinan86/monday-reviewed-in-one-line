A [make.fun](https://make.fun/c/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) entry: a program that writes the funniest one-line review of my Monday to `/output/entry.txt`.

## The line

> The printer jammed on page 2 of 3, which is the most honest thing it has ever done.

## Run

```sh
python3 main.py
```

Writes exactly one line (83 characters, no trailing newline) to `/output/entry.txt`. Deterministic: no network, no randomness, no clock, no file reads — two runs are byte-identical.
